Enabled capability boundaries:
- Mastodon-compatible public account lookup, profile statuses, selected status and
  descendant context. Login-only APIs and empty shells fail. No platform-provided
  comment popularity order; the reader says so. Federation servers may have
  incomplete data or different access policies; they are not complete mirrors.
- Mastodon public profile RSS is an independent format backup at the selected
  original server. Strict channel/profile and entry ownership checks; no arbitrary
  post, comment or older-page capability is claimed for the RSS path.
- Lemmy v3 community/person posts and selected-post comments. IDs stay qualified
  by the selected read instance. No claimed v4 compatibility before live testing.
- GETTR public post feed and selected public post. Comments/search are not enabled.
- Gab compact public status feed and verified v1 selected-status JSON.
  Comments/search are not enabled.
- Pixelfed public Atom profile feed. No arbitrary-post or comment capability.
- Telegram public channel previews and public message embeds with bounded older
  pages. No private chats, groups or discussion-thread comment capability.
- Misskey public user/note JSON reads. Notes have instance-local IDs; remote uri
  values are not treated as interchangeable API IDs. No comment capability or
  blanket Sharkey/fork compatibility claim.

All reads, redirects, media and optional diagnostics use NetworkGateway. Ordinary
traffic has no response log. PublicSocialAudit is an explicit developer diagnostic
which writes bounded public responses only to its external evidence directory.
Direct-network diagnostics do not establish Tor availability. Server/provider
access rules and returned data can change independently of an app release.
